# 增量文件投递目录

只放**标准化的 13 列 CSV**，不要放 Desktop 下的原始 45 GB 文件。

先写 `batch-001.part`，写完关闭后在同一目录原子改名为 `batch-001.csv`。
默认要求文件至少稳定 30 秒；`.part` 文件不会处理。不递归扫描子目录，拒绝符号链接。

每个文件默认最多 8 MiB / 200,000 行，每轮最多检查 5 个，目录最多 500 个 CSV。
成功后原文件保留，MySQL 中按完整内容的 SHA-256 去重；可手动归档成功文件以减少后续读取。
同名改内容会生成新指纹，同内容改名仍会跳过。失败的文件会记录错误类型并按退避规则重试。

自动调度默认关闭；开启方法、手动触发、任务记录和完整字段定义见项目根目录 README。
此目录的投递 CSV 和 `.part` 文件已加入 Git 忽略规则。
